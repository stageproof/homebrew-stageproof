# Security policy

Report a vulnerability through [stageproof/stageproof](https://github.com/stageproof/stageproof/security). Do not open a public issue for a security report.

What the Stageproof check does is in that repository's [SECURITY.md](https://github.com/stageproof/stageproof/blob/main/SECURITY.md). This tap installs the released binary.
